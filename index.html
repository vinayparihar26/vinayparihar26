Secure Chat Application

Privacy-Focused Messaging App

A highly secure, privacy-first messaging client inspired by Telegram features. Developed with Flutter and Dart, the application incorporates strict data security protocols, secure network communications via Dio, and automated access controls to prevent unauthorized sharing, screenshots, and identity exposure.

  • Privacy & User Discovery: Strict username-only search paradigm with email/phone OTP verification. Prevents general public discovery.
  • Anti-Capture Protections: Dynamic screenshot and screen recording blocking implemented at the native Android/iOS layer across private chat screens.
  • Forwarding Controls: Granular message privacy flags. Restricts copying, downloading, and forwarding of chats designated as private by the sender.
  • Advanced Messaging Rules: Blocked phone number detection, 3-day trial connection access limits, and hierarchical message deletion rules ("Delete for Everyone").
